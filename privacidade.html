Política de Privacidade do Luces Carretera

Última atualização: 11 de novembro de 2026.

O que o app faz

Luces Carretera usa a YouTube Data API, com a autorização do próprio dono do canal, para enviar e programar vídeos, definir miniaturas, títulos, descrições e tags, e ler estatísticas do próprio canal.

Dados acessados

O app acessa somente a conta do YouTube que o autorizou. O token de acesso fica guardado apenas no computador do dono, e nenhum dado é enviado a terceiros, vendido ou compartilhado.

Dados de outras pessoas

O app não coleta dados de espectadores nem de outros usuários do YouTube.

Como revogar

A autorização pode ser revogada a qualquer momento em myaccount.google.com/permissions.

O uso dos dados recebidos das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado.
